# 机会雷达 · 当日大涨预测

每个交易日，当地时间 09:25 分别为创业板、港股科技和纳斯达克冻结最多三只股票。目标是找到当天正常交易时段内，最高价能比前一交易日可比收盘价高出至少 5% 的股票。涨幅从昨收计算，看到榜单后实际还能获得多少涨幅，需结合开盘价、触及时段和收盘价判断。

## 盘前可见的三类证据

| 证据 | 首版门槛 | 页面上可核对什么 |

| 同行与个股共振 | 在同一名册、同一细分行业取至少五只其他股票。上一交易日同行涨幅中位数至少 0.5%，上涨占比至少 60%。个股涨幅达到同行中位数，且收盘价位于自身当日振幅的上部 30% | 同行数、同业涨幅中位数、上涨占比、个股涨幅。该证据反映前一交易日环境 |

昨日日成交额门槛分别为 2,000 万元人民币、1,000 万港元及 500 万美元。纳斯达克要求昨收至少 3 美元。通过基础筛选且至少两类证据成立才有资格进榜。先按证据数排序，再结合盘前成交相对同时间样本的倍数和同行强度排序。逐股分别记录已证实的条件、已证实未达标的条件和未知项。即使把未知项都算作成立仍凑不齐两类，才能确认该股未达标。只要未能判定的股票或缺失昨收仍可能改变零入选结果，显示“证据覆盖不足”。核实空榜要求所有名册成员均可判断。

能够核实的盘前成交价或有时间的盘前最高价已达到昨收的 105% 时，单独展示为「盘前已跳涨」。若当前盘前价格缺失，事件和行业两类证据仍可能支持进榜，卡片提示盘前价待核实。近期趋势本身仅能贡献一类证据。

## 数据范围与发布时间

- 创业板使用创业板证券名册、近期创业板公司公告标题、腾讯报价和行业分类。港股科技使用恒生科技综合指数名册、港交所主板及 GEM 的分批披露标题、腾讯与东方财富竞价行情和行业分类。港股 09:20 至 09:22 随机对盘；系统只接受有成交且时间、昨收可核验的报价。两家批量行情可能延迟，采不到时记为未知。
- 纳斯达克使用上市名册、发行人新闻稿、行业分类、CNBC 带交易时标的盘前报价与 Nasdaq 成交记录。因盘前逐笔接口按股返回，先用批量行情寻找线索，再优先核对有事件、同行共振或盘前异动的股票。标明延迟的盘前行情只能作线索或确认此前已经跳涨；最近成交需要有可核对的证券身份、交易时段和时间戳。未查到盘前成交的股票仍可用事件与同行两项证据评估。
- 先留存上一交易日收盘参考，三个市场均在交易日当地 09:15、09:20、09:22、09:23、09:24 采样。09:25 截止，最后一档暂时读不到时 09:28 重读，在 09:30 开盘前归档。采用原截止前完成的最新一档。每个市场、每档时点独立积累历史成交基线。新时点冷启动期间，依赖历史量比的个股可能暂时无法判定。结果保留该证据缺口，较早时点的名单不会补入。页面显示采样和发布时间，定时任务错过窗口则记录缺档。休市日显示下次冻结时间。
- 盘中确认另外记录一只股票首次触发的时间和价格，独立计算达到「收盘较昨收至少 +5% 且较触发价至少 +3%」的结果。

## 怎样知道有没有预测价值

1. 当日最高价达到可比昨收 × 1.05，计入盘中命中。按开盘已达和开盘后才达分别计数。
2. 收盘价仍然达到门槛，计为守住涨幅。盘中达到但收盘低于门槛，计为回落。另算开盘到收盘的收益率。只有连续有效的五分钟行情能证实首次触及时，才显示所在时间区间。
3. 每个市场用同一套价格和缺失规则，分别计算盘前主榜、当时完整候选名册及昨日涨幅前三的结果。展示已核实数、缺数据数、命中率、核实空榜及未能判定的天数。分母使用已核实数，并同时展示覆盖率。
4. 三个市场各自累计最近 20 个已复核交易日。观察从本版启用后起算，虚构示例独立显示。显示的历史命中率描述已发生的预测，个股未来上涨概率仍待独立样本检验和校准。

交易时段依据见[港交所证券市场交易时间](https://www.hkex.com.hk/en/Services/Trading-hours-and-Severe-Weather-Arrangements/Trading-Hours/Securities-Market?sc_lang=en)。港股收盘采集在收市竞价结束后进行，拒用早于随机对盘阶段的普通盘中报价。
